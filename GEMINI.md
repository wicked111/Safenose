# Safenose Project Rules

- **Project Name:** Safenose
- **Technology Stack:** Kotlin Multiplatform (KMP)
- **UI Framework:** Strictly Jetpack Compose / Compose Multiplatform.
- **UI Constraints:** No XML-based layouts are permitted. All UI must be implemented using declarative Kotlin code.
- **Architecture:** Feature-based modular structure within the `shared` and `composeApp` modules.
- **Dependencies:** 
  - Dependency Injection: Koin
  - Backend/Auth: Supabase
